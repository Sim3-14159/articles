CSS is a Programming Language

People sometimes will argue that HTML is a programming language. There are a lot of different definitions of a programming language, but loosely it's something like "a bunch of symbols or words that can cause calculations or decisions to be made."

You could probably also argue that a programming language has to allow the input and output of those calculations/decisions.

Does HTML qualify? No; HTML is a method of storing data, and also a method of displaying it. HTML doesn't have any way to calculate anything, even by editing the source file.

This is where I was thinking about CSS (specifically, modern CSS)—which even though almost nobody argues that it is a programming language—has some features that you would find in a programming language. The calc function can perform simple calculations, and the var function can retrieve data, which helps with output.

Now, this isn't a very good argument but I'm using it anyway: the first thing most beginner programmers will create is a simple calculator. If you can create a simple calculator using some form of text, then you can reasonably call it a programming language. This isn't both ways though; just because you can't create a calculator in a programming language doesn't mean it isn't one.

I've used AI to make a calculator with only CSS and HTML below (because I know that CSS could do it, I just didn't know the exact syntax to get it to do that). You may argue that I'm using HTML too; you'd be right, but the HTML isn't doing any calculations, it's just a means of showing the output, and getting input. That's similar to saying the following.

SQL isn't a real programming language because it can't output anything without having a database to output to.

And to that I would counter that a database is just a way of storing/outputting the information, just like HTML.

Anyhow, here's a very simple but 100% functional calculator, with all the logic programmed entirely in CSS.

CSS is not Turing-complete, but it can at least do some of these simple calculations. Before becoming Turing-complete in 1999, SQL was considered a programming language. In fact, there is no rule that a programming language has to be Turing-complete to be a programming language. It's just that Turing-complete languages are usually much more useful than ones that are not.
